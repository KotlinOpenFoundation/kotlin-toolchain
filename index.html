Kotlin Toolchain 0.13.0-dev-4307-fork-kof-1

A fork of JetBrains/kotlin-toolchain carrying fixes that are not in an upstream release yet. It is named after the upstream development version it is based on, so 0.13.0-dev-4307-fork-kof-1 is this fork of 0.13.0-dev-4307.

Install it in a project

A project that already has Kotlin wrapper scripts switches to this fork with its own update command:

./kotlin update -r https://kotlinopenfoundation.github.io/kotlin-toolchain/maven --target-version 0.13.0-dev-4307-fork-kof-1

A project without them takes the published scripts directly:

base=https://kotlinopenfoundation.github.io/kotlin-toolchain/maven/org/jetbrains/kotlin/kotlin-cli/0.13.0-dev-4307-fork-kof-1
curl -fsSLo kotlin "$base/kotlin-cli-0.13.0-dev-4307-fork-kof-1-wrapper" && curl -fsSLo kotlin.bat "$base/kotlin-cli-0.13.0-dev-4307-fork-kof-1-wrapper.bat" && chmod +x kotlin

Or install the toolchain for the user rather than for one project:

curl -fsSL https://kotlinopenfoundation.github.io/kotlin-toolchain/maven/org/jetbrains/kotlin/kotlin-cli/0.13.0-dev-4307-fork-kof-1/kotlin-cli-0.13.0-dev-4307-fork-kof-1-installer.sh | sh

The scripts carry the version, the checksum and the addresses below, so nothing else has to be configured: no environment variable, and no repository in any manifest. Modules of type jvm/amper-plugin need nothing extra either.
